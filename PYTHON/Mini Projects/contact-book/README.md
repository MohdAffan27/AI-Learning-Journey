# 📞 Contact Book

## 📌 Description

A simple Contact Book created using Python dictionaries.

---

## ✨ Features

- Add contact
- Search contact
- Display contacts
- Update contact
- Delete contact

---

## 🛠 Concepts Used

- Dictionaries
- Input/Output

---

## ▶️ How to Run

```bash
python contact_book.py
```
