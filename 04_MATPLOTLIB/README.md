## 💻 Basic Example

```python
import matplotlib.pyplot as plt

# Sample data
x = [1, 2, 3, 4, 5]
y = [10, 20, 15, 25, 30]

# Create a line plot
plt.plot(x, y, marker='o')

# Add title and labels
plt.title("My First Matplotlib Plot")
plt.xlabel("X Values")
plt.ylabel("Y Values")

# Display the plot
plt.show()
```
