# 🎓 Student Record File Manager

A simple Python project that manages student records using **file handling**. This project demonstrates how to store, retrieve, search, update, and delete student data from a text file.

## 📌 Features

- ➕ Add a new student record
- 📋 View all student records
- 🔍 Search for a student by name or ID
- ✏️ Update an existing student record
- ❌ Delete a student record
- 💾 Store data permanently using a text file

## 🛠️ Technologies Used

- Python 3
- File Handling
- Text Files (`.txt`)

## 📂 Project Structure

```
Student-Record-File-Manager/
│── student_file_management.py
│── students_record.txt
└── README.md
```

## ▶️ How to Run

1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```

2. Open the project folder:
   ```bash
   cd Student-Record-File-Manager
   ```

3. Run the program:
   ```bash
   python student_file_management.py
   ```

## 📚 Concepts Covered

- File Handling
- Functions
- Loops
- Conditional Statements
- String Operations
- CRUD Operations (Create, Read, Update, Delete)

## 🎯 Learning Outcome

This project helps beginners understand how Python can be used to manage data stored in files and provides hands-on experience with CRUD operations using text files.
