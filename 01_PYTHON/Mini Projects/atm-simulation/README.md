# 🏦 ATM Simulation

## 📌 Description

A console-based ATM simulation built with Python.

---

## ✨ Features

- PIN Verification
- Check Balance
- Deposit Money
- Withdraw Money
- Exit

---

## 🛠 Concepts Used

- Conditional Statements
- Variables
- Input/output
- Strings
- Lists
- Dictionaries
- Arithmetic Operators

---

## ▶️ How to Run

```bash
python atm_simulation.py
```

---

## 📷 Sample Output

```
Enter your PIN : <pin>

 Welcome Back <user_name>

====Select the Service you want====

1 . Balance Enquiry

2 . Deposit

3 . Withdraw amount

4 . Exit

Enter your choice :
```
