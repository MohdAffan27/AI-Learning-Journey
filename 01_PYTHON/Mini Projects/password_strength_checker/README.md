# 🔐 Password Strength Checker

## 📌 Description

This Python program checks whether a password is weak, medium, or strong using basic validation rules.

---

## ✨ Features

- Minimum length validation
- Uppercase check
- Lowercase check
- Numeric check
- Password strength evaluation

---

## 🛠 Concepts Used

- Strings
- Conditional Statements
- String Methods

---

## ▶️ How to Run

```bash
python password_strength_checker.py
```
