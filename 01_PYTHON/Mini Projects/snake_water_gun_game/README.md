# Snake Water Gun Game

A Python implementation of the classic Snake, Water, Gun game where the user competes against the computer.

## Game Rules
- Snake drinks Water → Snake Wins
- Water douses Gun → Water Wins
- Gun shoots Snake → Gun Wins
- Same choice → Draw

## Features
- Random computer choice
- User input
- Winner detection
- Draw handling
- Easy-to-understand game logic

## Concepts Used
- Variables
- Dictionaries
- Conditional Statements
- Nested if-else
- User Input
- Random Module

## How to Run

```bash
python snake_water_gun_game.py
```
