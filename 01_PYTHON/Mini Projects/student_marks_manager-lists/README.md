# 📚 Student Marks Manager

## 📌 Description

A Python program that stores student marks and performs basic analysis.

---

## ✨ Features

- Store marks
- Display marks
- Calculate average
- Find highest mark
- Find lowest mark
- Sort marks

---

## 🛠 Concepts Used

- Lists
- Tuples
- List Methods

---

## ▶️ How to Run

```bash
python student_marks_manager.py
```
