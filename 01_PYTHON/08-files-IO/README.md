# Python Practice – File Handling Exercises 


This folder contains Python programs that demonstrate practical file handling operations using text files. These exercises cover reading, writing, updating, and searching file content.


## 📂 Programs Included

1. Find a Word in a File

- Reads a text file.
- Checks whether a specified word exists.
- Displays an appropriate message if the word is found or not.

2. Save the High Score of a Game

- Stores the highest game score in a text file.
- Updates the file only when a new high score is achieved.

3. Multiplication Tables (2–20)

- Generates multiplication tables from 2 to 20.
- Saves each table in a separate text file automatically.

4. Replace a Word in a File

- Reads the contents of a file.
- Replaces a specified word with another word.
- Saves the updated content back to the file.

5. Search a Word from a File

- Searches for a user-provided word within a text file.
- Displays whether the word is present.

## 🛠️ Concepts Practiced

- File Handling ("open()")
- Read, Write, and Append Operations
- "with" Statement
- String Searching
- String Replacement
- Conditional Statements
- Loops

## 🚀 How to Run

1. Open the project in VS Code.
2. Ensure the required text files are in the same directory.
3. Run any program using:

python filename.py

## 📚 Learning Outcome

These exercises strengthen the understanding of Python file handling by working with real-world tasks such as storing data, searching text, generating files, and modifying file contents.
